## 2026-08-20｜第二章第一版可玩模块

### 本次实际完成

- 新建了一个可独立运行的 Web 游戏工程，没有修改用户提供的总 GDD。
- 实现了“半沙盒 + PPT 式”结构：固定 16:9 场景、地点自由切换、点击热点推进调查。
- 制作了三个可调查地点：档案间、院落、旧账房。
- 实现条件解锁：先在院落找到带红印的纸灰，旧账房才会开放。
- 制作六条关键证据，分为记录、物证、证词三类：被整页抽走的登记、重新描过的索引、带红印的纸灰、容姨改口的证词、多出来的一份女儿钱、两个人的删改签押。
- 实现一次完整推断：证据达到门槛后，玩家判断“谁开始删除她”。
- 实现错误判断反馈，不直接弹出正确答案。
- 实现正确判断后的章节结尾：确认长房下令、二叔执行，并触发第一次明确家族冲突。
- 实现本地自动存档、继续调查、重置本章、键盘快捷键和窄屏布局。
- 实现章节完成事件，供未来总工程接收第二章结果。
