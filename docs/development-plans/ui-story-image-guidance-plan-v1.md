# 《游园惊梦：四面证词》序章 + 第一章
# UI / 剧情背景图 / 地图 / 新手引导完整开发计划 V1.0

更新时间：2026-08-30

## 0. 本文用途

这不是“验证计划”，也不是“性能优化计划”。

这是一个 **Completion First（先完成）** 的开发执行文档，目标是把当前序章 + 第一章真正做成一个第一次进入就知道怎么玩、知道去哪、知道当前任务、关键剧情有足够表现力、能够连续游玩的 Vertical Slice。

本轮只做：

- 序章；
- 第一章；
- 开场操作引导；
- 右上角小地图 / M 键大地图；
- Esc 暂停 / 帮助 / 退出；
- 剧情背景图；
- 立牌与背景图组合；
- 当前任务、目标点、轻量世界引导；
- 与以上内容直接相关的轻量 Smoke Test。

本轮明确不做：

- 第二章以后大规模内容；
- 重型性能优化；
- 大量自动截图验收；
- 重型测试矩阵；
- 为了 FPS 删除 / 隐藏正式 Master 建模；
- 重新改 A / B / 山体 / 门窗 / 正式贴图；
- 每句对白都生成一张 CG；
- 一次性做完整游戏所有 UI。

# 1. 三条最高优先级原则

## 1.1 先完成，再正确，再好看，再优化

严格顺序：

1. 先让功能存在；
2. 先让序章 + 第一章能完整跑通；
3. 再修错误和体验断点；
4. 再统一美术和动画；
5. 最后再做性能优化和重验证。

禁止再次出现：

> 内容没做多少 → 先写很多测试 → 跑很多 Profile → 验证很多边缘条件 → 玩家仍然不知道怎么玩。

前期只允许最小必要测试，确保“新增内容没有完全坏掉”。

## 1.2 建模冻结

当前 Blender Master / GLB 是空间事实。

本轮 UI / 剧情 / 引导必须迁就现有建模。

禁止：

- 删除 A / B 正式建模；
- 删除山体；
- 删除正式树木；
- 删除门窗格栅；
- 为了任务路线强行改 Master；
- 为了 UI / 地图方便重新做场景拓扑。

如果任务点不好放：改任务点。

如果剧情位置不好：改剧情发生位置。

如果路线不好：改 Gameplay Route。

不要动 Master。

## 1.3 玩家必须始终知道“现在干嘛”

从玩家进入游戏开始，任何连续 20～30 秒内都不应该出现：

- 不知道怎么移动；
- 不知道怎么互动；
- 不知道当前目标；
- 不知道目标大概在哪；
- 不知道怎么打开地图；
- 不知道怎么退出 / 暂停；
- 不知道当前剧情为什么要求自己去调查某个东西。

我们的核心不是“把答案直接标出来”，而是：

> 给玩家足够的方向，让他主动调查，而不是在黑暗园林里瞎转。

# 2. 现有系统复用原则

## 2.1 立牌系统必须复用

现有角色透明 WebP 立牌继续使用：

- 赵映；
- 老周 / 老管家；
- 顾蘅秋；
- 园丁；
- 账房等后续角色。

不重新制作大批人物立绘。

普通对白继续采用：

> 实时 3D 背景 + 左右立牌 + 对话框。

## 2.2 复用现有 DialogueRunner 的 backdrop 思路

现有 `DialogueRunner.tsx` 已支持类似：

- `presentation === "stage"`；
- `sequence.backdrop`；
- 背景图 + curtain + portrait + dialogue box。

序章当前自定义的 `PrologueRuntime.tsx` 对话系统应补齐同样的 backdrop 能力，而不是再另造第三套完全不同的剧情 UI。

目标：

- 普通对话：3D；
- 关键剧情：backdrop；
- 两者共用相同人物立牌和文本节奏。

# 3. 图片生产总规则

## 3.1 CodeS 的图片职责

CodeS 可以生成图片。

本项目内对 CodeS 的图片职责定义为：

> 根据本计划中的画面规范生成剧情背景图、教程页图、地图底图和 UI 背景图，并保存到本地仓库指定目录，Runtime 直接引用。

生成后建议统一转：

- WebP；
- sRGB；
- 关键剧情图 1600×900 或 1920×1080；
- UI 背景图 1600×900；
- 地图底图 1024×1024 或 1400×1400。

## 3.2 统一风格

视觉关键词：

- 写实；
- 中式旧园林；
- 雨夜；
- 轻恐怖；
- 悬疑；
- 电影化构图；
- 低饱和；
- 冷色月光；
- 暖色灯笼；
- 雨雾；
- 湿地反光；
- 暗部保留细节。

禁止偏向：

- 二次元海报；
- 明亮古风写真；
- 纯水墨；
- 西式 Gothic；
- 过度华丽宫廷；
- 巨大科幻月亮；
- 和现有听雨轩建模完全不同的建筑布局。

## 3.3 剧情图的角色原则

剧情背景图不是人物写真。

画面优先级：

1. 空间；
2. 氛围；
3. 事件信息；
4. 人物。

如果人物已经用透明立牌表现，背景图里可以：

- 不出现正脸；
- 使用背影；
- 使用半遮挡剪影；
- 只出现灯笼、手、门缝等事件符号。

这样可以减少角色一致性问题。

# 5. 对话展示规则

## 5.1 普通对白模式

条件：对话不改变当前认知、不产生章节级信息、不需要固定电影机位。

表现：

- 3D 继续渲染；
- 背景略压暗；
- 左右立牌；
- 当前说话人高亮；
- 对话框；
- 允许自动 / 跳过已读 / 记录。

## 5.2 关键剧情 backdrop 模式

条件至少满足一项：认知被推翻、发现新的核心事实、章节开头/结尾、空间发生关键异常、需要明确构图和演出。

表现：

- 锁定玩家输入；
- 显示静态剧情图；
- 图上加轻微 vignette / 雨层 / slow zoom；
- 仍使用现有左右立牌；
- 仍使用文本系统；
- 对话结束淡回当前 3D 场景。

淡入淡出：180～300ms 黑场/crossfade；禁止瞬间白闪；禁止每句切图。

# 6. 开场操作引导设计

## 6.1 首次进入必弹

触发：New Game 且本存档 `tutorial.controls.seen !== true`。

标题：

> 调查须知

副标题：

> 进入听雨轩前，先记住你能相信的操作。至于你能不能相信自己的记忆——进去以后再说。

## 6.2 键位表

移动：W/A/S/D 移动，鼠标观察，Shift 快走。

调查：F 调查/交互，Tab 切换证词/认知，M 地图。

系统：H 帮助，Esc 暂停/设置/退出，Enter/空格/左键推进对白。

## 6.3 玩法提示

只显示三条：

1. 先记住空间，再调查痕迹。
2. 两个人的证词可以互相矛盾，但不代表其中一个人在撒谎。
3. 卡住时先看任务、地图和证词记录。

## 6.4 按钮

- `开始调查`
- `不再自动显示`

H / Esc → 帮助 中永远可以重新打开。

# 7. 序章任务引导重写

当前问题：“记住 A 区地标 0/3”对开发者明确，对第一次玩家不明确。

## 7.1 入门阶段

当前任务：

> 穿过主门，进入旧园。

提示：

> 老周让开了门。沿门内唯一完整的石路向前。

地图：主门位置、第一个目标点、玩家箭头。

## 7.2 建立空间记忆

任务：

> 先熟悉门内这一段路，确认 3 处空间参照。

子目标：

- [ ] 主门内的直行路径
- [ ] 转角灯的位置
- [ ] 墙 / 漏窗附近的位置

第一次激活任务时短提示：

> 以后有人会告诉你这里“不长这样”。先记住现在看到的。

## 7.3 三个点如何引导

不要永久巨大箭头。采用三级提示：

Level 0：小地图淡金目标点 + 任务文字。

Level 1（20 秒未进展）：显示距离，如 `转角灯 · 18m`，世界中出现低透明度微弱光圈。

Level 2（45 秒未进展）：老周/旁白一句提示：

> “先沿着门内的路走。灯在转角，漏窗在灯后。”

玩家可以在设置中关闭辅助引导。

## 7.4 证物阶段

完成 3 地标后，任务自动变：

> 确认七年前仍留在 A 区的痕迹。

子目标：

- [ ] 七年前的入园簿
- [ ] 与赵映有关的旧物 1/2

不要一开始就告诉玩家旧伞、旧鞋都在哪里。

地图只给入园簿明确目标点；旧物以搜索区域圈显示。

## 7.5 异常阶段

满足 3 地标 + 入园簿 + 至少一个额外旧物后，任务变为：

> 回到刚才记住的墙与转角。确认它有没有变化。

这里必须给明确地图点，玩家不应该靠记开发坐标找 Trigger。

## 7.6 异常发生后

触发 P-03，然后任务立刻更新：

> 回主门找老周。

地图目标：老周。

# 8. 第一章任务引导重写

## 8.1 第一章开场

标题：`第一章 · 不存在的路`

短目标：

> 不要先问谁撒谎。先确认现实里有没有人从这里经过。

## 8.2 现实痕迹

任务：

> 调查至少 3 处“有人经过”的痕迹。

列表：

- [ ] 墙脚水痕
- [ ] 泥脚印
- [ ] 倒灯拖痕
- [ ] 折断枝叶

规则：4 个中完成 3 个即可；第四个作为可选；地图显示 2～3 个大致搜索区域，不直接四个精确点。

## 8.3 夫人的墙

完成 3 痕迹后：

> 去听顾蘅秋描述这段墙。

关键对白后玩家亲眼确认“墙”。

## 8.4 老周的路

任务：

> 再看老周记得的同一个位置。

切换后出现“路”，此时触发 C1-01。

## 8.5 Loop

任务：

> 沿老周的路继续走。

第一次回到重复参照后触发 C1-02，然后任务更新：

> 你已经回到原处。保持位置，换一份认知再看。

明确提示一次：`Tab · 切换证词`。

## 8.6 Borrowed View

任务：

> 从漏窗看另一份空间。

完成后：

> 找到另一份认知中可以带走的构件。

如果 30 秒没找到：

> 踏石在夫人的认知里仍然完整。

## 8.7 Borrow / Anchor

第一次 Borrow 后出现一次短教学：

> 你借来的东西还不属于当前空间。找到锚点，把它固定下来。

任务：

- [ ] 借取踏石
- [ ] 找到 Anchor
- [ ] 切换认知确认踏石仍然存在

只有第一次显示详细解释，之后章节不再弹大教程。

## 8.8 打破 Loop

Anchor 完成后：

> 沿新的落脚点离开循环。

进入夹院。

## 8.9 夹院奖励

任务：

> 这里不在任何人的完整证词里。看看留下了什么。

可调查：身高刻痕、“雨大，别走正门”纸条、湿脚印。

完成 2/3 即可推进。

# 9. 小地图系统

## 9.1 默认位置

右上角，PC 建议 220～280px 方形；不遮挡状态指示，不遮挡剧情立牌；对话 backdrop 模式时隐藏或弱化。

## 9.2 小地图显示

必须：玩家位置、玩家朝向、当前主目标、当前区域名、`M` 键提示。

可选：已发现证物点、NPC、搜索区域。

禁止：Collider、Air Wall、Route Debug、Trigger 名称、开发坐标。

## 9.3 大地图

按 M：释放鼠标、暂停玩家移动、显示全图、当前区域高亮、当前任务文字、支持 Esc/M 关闭。

地图不是传送菜单，本轮不做 Fast Travel。

# 10. Pause / Help / Exit

## 10.1 Esc 行为

Esc 第一次打开 Pause：继续、地图、帮助、设置、返回案卷。

## 10.2 鼠标

Pause / Map / Help 打开时退出 pointer lock、显示鼠标；关闭后玩家点击“继续”重新获得 pointer lock。

不要让玩家不知道鼠标去哪了。

## 10.3 Help 内容

帮助页包含：操作、当前章节玩法、任务/地图/证词记录怎么用、重新显示开场教程。

# 12. 图片 Prompt 规范模板

## 12.1 基础风格 Prompt

```text
写实电影感中式旧园林，雨夜，低饱和，青灰与墨绿色主色，湿润砖墙与石板反光，冷色月光，局部暖灯笼，真实雨雾，轻微中式恐怖和悬疑氛围，空间结构清晰，建筑比例真实，画面暗但保留材质细节，不是二次元，不是水墨，不是明亮古风写真，不是奇幻宫殿。
```

## 12.2 序章门口附加

```text
旧园主门半开，门内有一个年长管家守门，人物偏剪影与侧身，不要占满画面；镜头位置接近玩家第一人称到电影过场之间，门内园林在雨幕后若隐若现，灯笼暖光只照亮局部，构图给左右人物立牌保留空间。
```

## 12.3 空间异常附加

```text
同一处中式园林转角，真实建筑没有魔法发光；视觉上出现“刚才有开口的位置现在变成完整砖墙”的不可能变化，同一盏灯和树仍保持原位置，让观众通过参照物意识到空间被改写，恐怖来自现实不一致而不是怪物。
```

## 12.4 Loop 附加

```text
中国园林曲廊夜雨，同一盏灯、同一漏窗和同一树在前方再次出现，道路看似一直向前却回到相同空间，轻微视觉重复和透视错位，保持写实，不做抽象迷宫或科幻空间。
```

# 14. 开发执行顺序

这是整个文档最重要的部分。严格按顺序做。

## Stage 0 — 资源和配置骨架

只做：创建目录、`story-backdrops.ts`、`map-config.ts`、`guidance-config.ts`、图片 Manifest、图片 fallback。

完成条件：不报编译错误，没图时游戏仍能进入。

测试：仅 1 个 Smoke，资源表能 import。不要做更多测试。

## Stage 1 — 开场教程完整做出来

先做 UI，再生成图。

功能：New Game 首次弹出、开始调查、H 重新打开、Esc→Help 可以打开、存 `tutorial.controls.seen`。

然后 CodeS 生成 UI-01 图。

完成条件：玩家第一次进入，能在 20 秒内知道怎么走、怎么查、怎么开地图、怎么暂停，以及这个游戏不是找谁撒谎，而是比较认知。

测试：首次打开、关闭、H 重开。停止。

## Stage 2 — 地图功能完整做出来

先用临时灰底/程序块完成逻辑，不要等精美地图图。

功能：右上角 MiniMap、M 打开 FullMap、玩家位置、朝向、当前目标、未开放区域。

然后生成 MAP-01 / MAP-02 替换临时底图。

测试：M 打开关闭、玩家走动地图点跟随、当前目标更新。停止。

## Stage 3 — 序章引导完整做出来

先不要做剧情图。

保证：主门目标→3 个空间参照→入园簿→旧物→返回异常点→回老周。

全部任务文字 + 地图引导 + 轻 world marker 做通，加入 20s/45s 两级提示。

完成条件：一个不知道开发坐标的人也能自己玩完序章探索部分。

测试：只从进门玩到回老周一次，不做自动化大矩阵。

## Stage 4 — 序章 4 张剧情图

CodeS 依次生成 P-01、P-02、P-03、P-04。

不要一次生成 20 张。

每生成一张：保存到正确目录、检查尺寸、接入对应剧情节点、能触发即可继续下一张。

完成后再统一看风格。

测试：四个剧情节点各点一次。不做每一帧截图验收。

## Stage 5 — Pause / Help / Exit

功能：Esc、鼠标释放、继续、地图、帮助、设置入口、返回案卷。

生成 UI-02 / UI-03。

测试：Esc 开、继续、返回案卷。

## Stage 6 — 第一章引导完整做出来

先完成逻辑，不等图片。

顺序：3/4 现实痕迹→夫人的墙→老周的路→Loop→切换认知→Borrowed View→Borrow→Anchor→打破 Loop→夹院 2/3 证据→A→B。

每一步必须：左上目标可读、地图提供合理方向、30～45 秒无进展可获得提示。

测试：只完整走一遍。

## Stage 7 — 第一章关键剧情图

先生成 C1-01、C1-02；时间充足再 C1-03 Borrowed View、C1-04 Hidden Yard。
