# V0.1 / V0.1R 实施记录 · 2026-08-25

## V0.1R 新手体验重做

- 将首页文本序章与游戏内 `briefing` 弹窗合并为连续可玩的“序章＋西廊”流程；版本标记为 `V0.1R Onboarding Slice`，不再暗示已经达到 V1.0。
- 接入 MIT 许可 `inkjs`。Ink 源文件、编译 JSON、对话标签解析和分支终止测试均进入仓库。
- 完成开场、夫人问询、园丁问询、第一笔勘误解释、第二轮交叉核验、信任判断、追逐揭示和章节尾声八段数据化对话。
- 完成 `ObjectiveDirector`：单一主任务、方向/距离、3D 标记与 60/120/180 秒递增软提示；对话、菜单和追逐时暂停计时。
- 第一项矛盾按“夫人观察 → Tab 切证词 → 园丁复查 → 自动打开勘误簿”教学；第二项只给目标和观察方向。
- 存档键仍为 `garden-of-shadows.save.v2`，新增对话状态、已读台词、任务步骤、提示等级和鼠标锁恢复字段；旧 V2 数据通过默认值归一化。
- 生成并接入沈照影、管家残影、顾蘅秋、周守圃共 12 张透明 WebP 工笔重彩立牌；记录生成 ID、提示词、Alpha、聚合哈希和修改步骤。
- 完成 Azure 预置普通话声线、SSML 模板和许可状态清单。当前没有项目 Azure 付费凭据，因此正式 OGG/MP3 标记为 `credentials-required`，运行时不伪装成已完成配音。
- 提高 ACES 曝光、环境光、灯笼局部光和地面反射可读性，并加入脉冲式任务标记，修复旧截图中路径和目标接近全黑的问题。
- Blendkit/Poly Haven 资源进入候选许可台账；当前环境没有 Blender，129 MB 高模不能安全减面和导出，因此未把未经优化的源模型直接放入 Web 包。

## 有意保留的边界

- V0.1 的园林是核心玩法所需的程序化白盒，不冒充最终 3D 资产。
- 候选第三方模型未下载。许可、Web 分发与 NoAI 结论明确前不得进入运行时。
- 序章当前为高质量文本交互；第二至第八章已经有清单和依赖，尚未冒充可玩完成内容。
- 预渲染视频接口已经进入资产包字段，V0.1 尚未放入伪占位视频。
