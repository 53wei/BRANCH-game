## 如何启动

要求 Node.js 版本不低于 22.13。

在终端进入：

```powershell
cd "C:\Users\L\Documents\ChatGPT\借景\BRANCH-game-review\garden-of-shadows-game"
npm ci
npm run dev
```

终端出现地址后，浏览器打开：

```text
http://localhost:3000/
```

向下找到章节列表，点击“第二章·北楼暗账”右侧箭头。

如果要从头重新测试，可在首页进入“设置”，点击“仅清除《游园惊梦》存档”，然后重新进入第二章。

## 操作方式

- `WASD`：移动
- 鼠标：观察
- `F`：勘验、上楼、穿过借景窗、推动假山
- `Tab`：切换账房、夫人、园丁证词
- `Shift`：加速移动
- 对话中使用鼠标点击，或按 `Space` / `Enter` 推进

## 完整试玩步骤

1. 进入第二章并完成开场对话。
2. 沿金色标记走到楼梯口，按 `F` 上二层。
3. 在账房证词中走到蓝色借景窗，第一次按 `F` 检查，第二次按 `F` 进入过去。
4. 在过去靠近完整假山，按 `F` 推动。
5. 回到庭院入口的借景框，按 `F` 切回现在。
6. 用账房证词检查窗框划痕；按 `Tab` 切到夫人证词，在同一位置再次按 `F`。
7. 切回账房证词检查秘密通道；再切到园丁证词复查。
8. 完成对话中的三选一信任选择，看到“第二章完成”。

## “审查”是什么意思

Codex 中的“审查”是查看本分支相对原始代码发生了哪些增删改，也叫代码差异检查。它用于在提交或合并前确认是否改错文件、是否存在明显问题或合并冲突。

“审查”不会运行游戏，也不代表代码已经提交或推送。
