# 测试与验收基线

## V0.1R 新手体验门槛

- 5/5 玩家在开场后能复述“勘验人、同地异景、两份独立证词、写入勘误簿”四项核心信息。
- 4/5 玩家两分钟内抵达第一观察点，五分钟内确认第一项矛盾。
- 任一有效任务步骤无进展 60 秒给环境提示、120 秒给区域提示、180 秒给操作提示；对话和勘误簿期间不得计时。
- 每个 Ink knot 与所有选择都必须可结束；每个 `speaker`、`portrait`、`voice` 与任务命令必须通过构建前校验。
- 对话中刷新最多重复当前一句，不能跳过选择、重复写入非幂等状态或永久丢失鼠标锁。

## 自动门禁

- 章节清单顺序、唯一 ID、解锁依赖与估时合法。
- 存档键固定为 `garden-of-shadows.save.v2`；损坏或旧版本数据回退到默认值；不触碰旧项目键。
- 空间矛盾必须由清单要求的全部独立证词确认，重复观察不得重复计数。
- 信任选择只改变道德标记，不得伪造或删除客观证据。
- 三结局条件、四姓名锚点和追逐检查点可由纯规则函数验证。
- 许可清单中只有 `approved` 且具备来源、许可证、Web 交付结论和哈希的运行时资源可发布。

## Portal 与切层用例

每个 Portal/记忆切换逐项测试位置、朝向、期望速度、碰撞层、连续切换、目标区域占用与安全锚点。至少覆盖：静止切换、贴墙切换、斜向快走进入、追逐中切换、低帧率连续切换。禁止穿墙、坠落、绕过谜题、重复传送与累计坐标漂移。

## 视觉回归

当前第一阶段只验收正式建筑视觉层，不把水院或第二章混入同一门禁。固定摄像机、天气种子与画质，必须生成：

1. 出生点正视图：真实 Siheyuan 正门 / 前厅进入第一眼构图。
2. 前厅视图：真实 Siheyuan 建筑组团承担主视觉。
3. 西院视图：真实 Courtyard Park 与少量正式植被承担围合与园林语汇。
4. 曲廊视图：至少一次转折，禁止 `TYX_ARCH_Kit_A` 正常出现在 `visualAssets`。
5. 漏窗 / 月洞门视图：真实园林构件承担建筑主体，程序 Torus 只允许作为记忆高亮效果。

允许雨滴单帧位置变化；建筑轮廓、可交互标识、雾层可读性和色温偏差必须在基准阈值内。五张图、FPS、draw calls、triangles、loadedAssetBytes 由 `npm run visual:capture` 记录，最终仍需人工视觉确认。

## 盲测

- 每谜题至少 5 名未读设计稿玩家。
- 80% 无需查看答案即可描述核心规则。
- 单次无进展 ≤ 3 分钟；软提示只指出观察方向。
- V0.1R 序章 4–6 分钟，西廊 12–18 分钟，合计目标 16–24 分钟。
- 追逐平均重试 ≤ 1 次；失败回退 ≤ 20 秒。
- 稳定模式、无声音、字幕开启仍可完整解谜。

## 发布四签

功能、性能、资产许可、AIGC 来源四项全部通过且 `phase-one-acceptance.json` 人工视觉状态为 `approved` 才可标记发布。缺少许可记录的资源直接阻止正式构建。当前核心中式模型已经下载、哈希审计并接入 RuntimeAssetLoader；但正式视觉重建后的本机运行、五截图和性能实测尚未执行，因此 `release-approval.json` 必须保持 pending。
