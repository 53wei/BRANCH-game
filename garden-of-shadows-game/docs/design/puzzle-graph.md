# 序章加八章谜题依赖图

## 战役主图

```text
P0 正常园林基线 / 接受勘验身份
 └─ C1 双记忆切换 → 逆向水痕 → 回环反转 → 信任重构 → 追逐 1
     └─ C2 漏窗借景 → 错时账页 → 过去/现在互相改路
         └─ C3 透视教学 → 找到画门 → 门内外尺度组合 → 追逐 2
             └─ C4 唱段顺序 → 四景时序 → 第五声部反转
                 └─ C5 四证词配对 → 可信度排序 → 共同删除对象
                     └─ C6 反锁条件 → 唯一可达路径 → 死亡顺序锁
                         └─ C7 身体记忆 → 四次破坏 → 第五视角/姓名恢复
                             └─ C8 四姓名锚点 → 关系推断 → 追逐 3 → 三结局
```

## 每章三段规则

| 章节 | 规则教学 | 两规则组合 | 规则反转 | 防卡软提示 |
|---|---|---|---|---|
| 序章 | 基准园林可被勘验 | 声音与物件互证 | 管家也属于待核验对象 | “先记住没有下雨时，水往哪里流。” |
| 西廊 | 铜铃区切记忆 | 同一水痕双视角观察 | 用错误的夫人月门逃出园丁循环 | “别用同一份证词寻找出口。” |
| 北楼 | 漏窗借景改变远景 | 时钟与账页组合开路 | 让过去的门出现在现在 | “窗框没动，借来的景动了。” |
| 画中缺门 | 透视线相交成门 | 画内尺度与真实碰撞组合 | 主动走入错误透视 | “只有站错位置，门才画得对。” |
| 未演还魂 | 唱词控制四景次序 | 锣点与角色站位组合 | 演出缺失的一拍，听见第五声 | “空拍也属于唱段。” |
| 四面锁 | 每人一真一假 | 可信度权重交叉验证 | 保留谎言以显出共同保护对象 | “不要先删除假话，先问假话遮住谁。” |
| 水榭无门 | 锁舌与水位独立排序 | 画门消失和逆灌组合 | 从不可达性反推唯一逃生方式 | “先证明哪些路绝不可能。” |
| 无名证词 | 掌伤触发身体记忆 | 姓名碎片与四人动作组合 | 玩家成为被核验的证词 | “勘验簿上的笔迹和你一样。” |
| 惊梦还魂 | 姓名锚点固定空间 | 四锚与关系判断组合 | 通过放弃控制保住所有证词 | “名字可以被拥有，也可以只被记得。” |

## 软提示层级

1. 60–90 秒无有效进展：环境声聚焦观察方向。
2. 120 秒：勘误簿高亮仍缺哪一份独立证词。
3. 180 秒：字幕指出应观察的对象类别，不给结论。

提示不得自动完成交互，不得说出最终因果。稳定镜头、静音和低画质都必须保留等价的视觉或文字线索。
