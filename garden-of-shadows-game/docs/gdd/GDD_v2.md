# 《游园惊梦：四面证词》GDD v2

状态：V0.0 设计定案；V0.1 垂直切片实施中
首发：PC Web；中文；单人；16+ 强心理恐怖；6–8 小时
边界：无战斗、无跳跃、无常驻敌人、无随机巡逻；全篇三次短促叙事追逐

> 本文是正式制作基线。根目录 `GDD_游园惊梦_完整版.md` 视为 GDD v1 历史稿，不回写。

## 1. 一句话体验

玩家在四名证人的记忆中反复穿行同一座苏州园林，用空间而非口供确认矛盾，最终发现自己正是四份证词共同删去的第五个人。

## 2. 设计支柱

1. **园林就是证词**：每一名证人都修改同一基准园林的材质、声场、可见物与可达拓扑。
2. **事实唯一，责任不唯一**：案件有且只有一条可重建因果链；人物动机、可原谅性和结局由玩家判断。
3. **玄幻有固定规则**：姓名是锚，证词是界，戏词是指令，四景同时成立才可借名还魂。规则可以组合和反转，不能临时添加例外。
4. **恐怖必须提供信息**：追逐、异象与失败都要交付证据、规则或身份揭示；不以随机跳脸拖延玩家。
5. **高密度空间**：重要线索在 30–90 秒步行半径内形成可复查关系，避免无意义折返。

## 3. 玩家身份与主冲突

玩家角色沈照影是园主沈砚堂未公开承认的女儿，也是昆曲旦角传人。沈砚堂发现姓名可以借四份互相承认的证词固定，于是设计“四景还魂局”：四名见证者依次确认名帖、水路、时辰与画门，抹去第五席原本的主人，再让自己借她的姓名存续。

当夜四人各自察觉一部分危险，并在没有完全串通的情况下破坏仪式：

- 顾蘅秋（夫人）偷换名帖，让仪式无法完整写定“沈照影”。
- 周守圃（园丁）改动水路，切断水榭与四景的正常循环。
- 陆文修（账房）错置仪式时辰，使四景不能在同一时刻成立。
- 许停云（画师）绘制不存在的逃生门，为照影留下拓扑出口。

照影打碎定名镜并从画门逃离。画门随即消失，改道后的逆流水灌入反锁水榭，沈砚堂溺亡。四人事后从口供中删去照影，借集体否认终止仍在运行的仪式；代价是她真的失去名字与当夜记忆。

## 4. 核心循环

`建立基准空间 → 进入证人记忆 → 学习该记忆规则 → 在同地切换另一证词 → 两份独立观察确认矛盾 → 写入勘误簿 → 重构动机/信任 → 改变拓扑 → 到达下一证据`

单个谜题采用三段式：

- 规则教学：一次只引入一个记忆差异，失败成本近乎为零。
- 两规则组合：同一线索必须在至少两份独立证词中观察。
- 规则反转：玩家利用“错误证词”本身开路，而不是只找出它错误。

## 6. 结局

### 写真

公开完整责任链并恢复本名。四人承担各自动作的后果，但不被简化为合谋凶手；听雨轩失去记忆拓扑，退化为普通园林。

### 借名

接受“沈砚堂”作为权力与合法身份。照影得以继承庄园，园主也借她继续存在；下一轮来访者会把她称为管家。

### 放河灯（隐藏）

收齐全部空间矛盾与四枚姓名锚点后解锁。保留证据，烧毁还魂谱，让五份证词脱离园主控制；没有任何人替另一人决定名字。

## 7. 表现与镜头

- 第一人称日常勘验；关键证词可短暂转为固定构图。
- 角色不依赖低质量实时面部近景：证词肖像、回忆、章节转场使用高质量生成图或预渲染视频。
- 镜头畸变只表达证词切换，不承载解谜信息；稳定模式关闭畸变后仍可通关。
- 暴力以声音、物证和空间后果呈现，不展示猎奇尸体。

## 8. 技术基线

- UI/章节/存档：Vinext + React。
- 运行时：客户端 `GameRuntime`；Three.js `WebGPURenderer`；Rapier 胶囊体。
- 后端适配：所有渲染选项经 `RendererAdapter`；用户可强制 WebGL 2。
- 场景：共享基准层 + 当前记忆层 + 切换目标层；垂直切片最多一个 Portal，正式章节最多两个。
- 资源：GLB/glTF；Meshopt/Draco；KTX2；H.264 MP4；章节流式加载。
- 存档：`garden-of-shadows.save.v2`。旧 `undying-world.game.save.v1` 不迁移、不删除。
- 事件：`garden-of-shadows:chapter-complete`，固定载荷 `{ chapterId, earnedFlags, contradictions, trustDecision?, endingId? }`。

## 10. 内容边界

苏州园林、《牡丹亭》和中元民俗用于提炼空间与戏曲规则，不复刻受保护园林扫描，不宣称虚构仪式为真实民俗。现成资产必须完成来源、作者、许可、Web 交付与 AI 使用限制审计后才能进入发布包。
