## 唯一死亡链

`水榭从内反锁 → 照影进入第五席 → 定名镜被打碎 → 照影经画门离开 → 四景失配、画门消失 → 暴雨触发改道水路逆灌 → 沈砚堂无法离开 → 溺亡`

任何单一证人的行为都不足以单独造成这条链：没有换帖，园主可先完成借名；没有改水，不会逆灌；没有错时，四景会稳定；没有画门，照影也被困在水榭。四次保护性破坏的组合救出照影，却构成了园主死亡的物理条件。

## 玩家发现顺序

1. 先看见密室溺亡结果，误以为四人之一制造了出口。
2. 发现水路被改，形成“园丁谋杀”表层答案。
3. 发现时辰错置与画门，意识到多人分别改动过现场。
4. 发现第五席，误以为四人合谋牺牲未知第五人。
5. 确认四人都删去同一人，推断删除具有共同目的。
6. 还原唯一死亡链，确认无人能完整预见组合后果。
7. 开启第五视角，发现玩家既是被保护者，也是打碎镜子和逃离密室的人。
8. 识破“管家”即园主残影，选择如何处置姓名、证据和四人责任。
